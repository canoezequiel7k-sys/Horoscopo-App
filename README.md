🔮 HoroscApp

HoroscApp es una aplicación móvil desarrollada para explorar el mundo de la astrología y la adivinación desde una interfaz simple e intuitiva.

La aplicación cuenta con tres funcionalidades principales:

🔮 Horóscopo — Consulta información relacionada con tu signo zodiacal.
🃏 Cartas — Realiza una lectura de cartas para obtener una interpretación.
✋ Palmistry — Explora la lectura de la palma de la mano.
📱 Funcionalidades
🔮 Horóscopo

Permite al usuario consultar su horóscopo y descubrir información relacionada con su signo zodiacal.

🃏 Lectura de cartas

Una sección dedicada a la lectura e interpretación de cartas, ofreciendo una experiencia interactiva para el usuario.

✋ Palmistry

Sección dedicada a la quiromancia, donde el usuario puede explorar diferentes aspectos relacionados con la lectura de las líneas de la mano.

🛠️ Tecnologías utilizadas

Android

🏗️ Arquitectura

El proyecto está organizado separando las diferentes funcionalidades de la aplicación para mantener el código organizado y facilitar su mantenimiento y escalabilidad.
